# HTH INDIA 2.0 – Hack The Hardware India

This is the official repository for **HTH INDIA 2.0**, a PAN-Level Hardware Innovation Competition held at Suryodaya College of Engineering & Technology (SCET), Nagpur.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, ShadCN UI, Framer Motion
- **3D/Graphics**: Three.js, React Three Fiber
- **AI Engine**: Genkit with Gemini 2.5 Flash

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Variables**:
   Create a `.env` file and add your Google AI API Key:
   ```env
   GOOGLE_GENAI_API_KEY=your_api_key_here
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
