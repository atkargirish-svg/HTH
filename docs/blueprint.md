# **App Name**: HTH INDIA

## Core Features:

- Cinematic Circuitry Loader: A high-end pre-loader that draws procedural PCB traces and electrical pulses using SVG animation before revealing the site.
- Motherboard Narrative Timeline: An interactive vertical timeline designed like a hardware motherboard where nodes glow and react to scroll progress via GSAP.
- AI Hardware Track Scout: Uses an AI tool to analyze team hardware summaries and intelligently suggest specific tracks and project categories.
- Magnetic Interaction Engine: A custom cursor system that utilizes magnetic attraction for buttons and 3D tilt effects for hardware project cards.
- Dynamic Stat Matrix: Animated data visualization section using JetBrains Mono typography to showcase real-time participant and prize statistics.

## Style Guidelines:

- Primary background: Deep Obsidian (#05070B) with premium glass cards at rgba(255,255,255,0.05).
- Brand Accent: High-energy Hardware Orange (#FF8A00) with a technical cyan highlight (#36CFFF) for small accents.
- Headlines: Space Grotesk for a modern engineering feel. Technical data: JetBrains Mono for a monospaced code aesthetic.
- Luxury minimalist layout with extreme whitespace, asymmetrical grid balancing, and floating glass-blur navigation.
- Premium cinematic transitions using Framer Motion and GSAP, featuring staggered word reveals and parallax blueprints.
- Monolinear, geometric Lucide icons with consistent stroke weights and soft glows on hover.
